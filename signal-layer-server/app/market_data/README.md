# 行情数据管理

`MarketDataManager` 是应用读取 K 线的唯一数据管理层，所有行情接口、指标、缠论、策略评估和回测均通过 `DataService` 进入该模块。

## 读取顺序

1. 从 MySQL 的独立行情表读取数据，表名遵循 `{标的}_{周期}`，例如 `000001_sz_日线`、`RB0_5分钟`。
2. 读取 `_market_data_coverage` 中已经向外部数据源确认过的时间区间。
3. 用请求区间减去已覆盖区间，只向外部行情 API 请求缺失部分。
4. 使用 `date_time_int` 主键批量写入或更新行情表。
5. 合并覆盖区间，再从数据库查询并返回完整结果。

覆盖区间元数据用于区分“没有交易的周末/节假日”和“尚未获取的数据”，避免空日期反复请求 API。

## 接口

最近 N 根：

```text
GET /api/v1/klines/000001_sz?timeframe=5m&limit=500
```

指定闭区间（Unix 毫秒）：

```text
GET /api/v1/klines/000001_sz?timeframe=1d&start_time=...&end_time=...
```

相同标的、相同周期的并发缺口请求会串行合并，避免前端 K 线、指标和缠论同时加载时重复调用外部 API。
